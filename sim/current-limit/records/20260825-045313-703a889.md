- **Claim**: Substantiates spec/target-spec.md's DRAFT "Current limit" row (constant-current (brickwall) clamp, window TBD over PVT; never engages for I_load <= 50 mA; survives continuous Vout = 0 short at Vin_max) against the sense-FET current comparator and gate clamp issue #22 added to design/ldo_3v3in_1v8out.sch (M_SENSE / M_CLN1 / M_CLN2 / M_CLP / M_CLIM -- see design/README.md's "Current limit (#22)"). The row is DRAFT (issue #1 not yet ratified) and it deliberately carries NO numeric clamp window: the window is "TBD over PVT". This experiment therefore splits the row rather than blurring it -- the clauses that carry a number are bounded below ("never engages for I_load <= 50 mA" becomes ilim_short_ma/ilim_knee_ma > 50 mA plus vout_50ma_v inside the DRAFT Output row's 1.764-1.836 V window), and the clause that does not ("window TBD over PVT", "survives") is measured and reported WITHOUT a bound, because establishing that window over PVT is exactly what the row asks for at this stage; inventing a ceiling would be the invented settled number CLAUDE.md forbids. "At Vin_max" is covered by the corner runner's own supply axis (the 3.63 V column), not by a hard-coded VIN. The short is applied as an event at t=0.5ms and HELD to t=2.5ms -- 2 ms of continuous Vout = 0, a defined duration rather than a single sampled instant, since "survives" is a claim about holding the fault. Known-caveat, stated rather than hidden (design/README.md, "Known accuracy caveat"): M_SENSE is a 0.42um replica of a 2500um pass device whose drain does not sit at VOUT, so the 1:5952 ratio is neither Vds-matched nor trimmed and carries substantial random Vth mismatch -- this corner-matrix experiment measures the systematic PVT window only; the mismatch axis would need a Monte Carlo experiment (sim/bin/mc-run.py), which is not in this issue's scope.
