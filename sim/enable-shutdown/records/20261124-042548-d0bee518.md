- **Experiment**: `enable-shutdown` — Enable / shutdown: shutdown Iq, Vin->Vout leakage, and no active discharge
- **Claim**: Substantiates spec/target-spec.md's ratified "Enable / shutdown" row (shutdown Iq < 3 uA worst corner; disabled output = pass device fully off, no active discharge; Vin->Vout leakage <= 1 uA) against the EN-gated shutdown path in design/ldo_3v3in_1v8out.sch -- the M_ENP/M_ENP2/M_ENP3/M_ENP4/M_ENP5 clamp family and the M_ENN/M_ENN2 pseudo-ground switches, see design/README.md's "Enable/shutdown (also revised after simulation)". The row is ratified by issue #1 / DR-006; the bounds below cite its own two numbers (3 uA, 1 uA) verbatim rather than an invented final limit. Three deliberate method choices: (1) shutdown Iq is measured both statically (EN held at 0) AND 1.5-2.5 ms after a falling EN edge, because a DC-only check cannot distinguish a block that HAS a clean disabled solution from one that actually REACHES it -- vout_pre_disable_v witnesses that the transient leg really was regulating before the edge, so the check cannot pass vacuously. The transient leg runs a full enable -> shutdown CYCLE (EN low at t=0, rising at 100 us, falling again at 2 ms) rather than starting already-enabled: starting enabled would make the leg depend on ngspice's t=0 DC solve landing on the regulating branch, which it does not at the ff/sf 125 C corners (design/README.md's "What the full 45-point PVT + Monte Carlo campaign's FAILs actually mean", mechanism 1 -- thermal-clamp nuisance trip, issue #69), so that draft failed those corners for a reason unrelated to the enable/shutdown path. (2) Vin->Vout leakage is measured with VOUT forced to 0 V, which is what isolates the clause: at VOUT = 0 the block's ~3.1 MOhm feedback divider carries no current, so the forcing source collects the VIN->VOUT path and nothing else. (3) "no active discharge" is bounded via the transient residual output 2 ms after the disable edge with no external load (the only discharge path a correctly disabled block has is the divider, whose R_div x C_OUT constant is seconds), checked against the ratified Output row's own +-2% window rather than an invented discharge-current threshold; the static counterpart -- the current a disabled block draws from an output held at 1.8 V -- is reported rather than bounded, because separating the divider's inherent preload from an active discharge by DC current alone would need a divider value this experiment does not independently measure. Stated coverage limitation: the row's "pass device fully off" clause is substantiated by the leakage measurement, not by a per-device check inside the DUT.
