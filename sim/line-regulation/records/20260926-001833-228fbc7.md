Initial-condition contract (#171, converted by #172): each of the four points is a COLD-START, SETTLED transient ('tran 10u 200m uic' with the testbench's VEN stepping high at 101us, v(vout) averaged over the settled 199ms-200ms tail), NOT the bare unconstrained '.op' this bench used through record 20260925-114251-1f54ca6. Every node starts at its natural cold value with the block disabled and powers up through its own soft-start ramp, so there is no operating-point solve in the deck at all -- the contract's 'uic' + EN-edge shape, the one PR #170 landed for sim/mc-output-accuracy. That matters because an unconstrained '.op' is not a physically realizable state of this block (#164 / PR #170: 12 of 200 mc-output-accuracy draws settled with FB above the only node feeding it, up to 1.3e15 V), and because the superseded record is the worst case of the same defect: all 45 of its corners carry a solver diagnostic (44 'singular matrix', 1 'Dynamic gmin stepping failed' plus 'out of range for ^') on the same three sky130_fd_pr__res_xhigh_po instances (xldo.ea_cz, xldo.amp_enn, xldo.n_fbb), which sim/bin/corner-run.py's #171 gate now forces to FAIL outright. Measured during #172 and the reason these are 'uic' transients rather than seeded 'op' cards: a seeded DC solve does not close the gap in ngspice -- '.ic' is honoured only for the operating-point solve preceding a non-'uic' transient and a bare 'op' ignores it, while '.nodeset', which a bare 'op' does honour, still printed 'singular matrix' plus 'Dynamic gmin stepping failed' at 3 of 5 corners probed. Cross-check that the start state is not steering the answer: an '.ic'-seeded non-'uic' settled transient reaches the same tail, agreeing to six digits on all four points at tt/27C/3.30V and to 31.2/43.9 mV/V at tt/125C/2.97V. Known risk, not a testbench defect: the same design/README.md section (mechanism 1) documents a thermal-shutdown false-trip at the ff/sf process corners at 125C, independent of load current -- tracked by #69, which re-sized that shutdown. #172's cold-start re-run is this bench's first 45-corner record against the post-#69 DUT with a physically realizable start state, so its ff/sf 125C numbers are a fresh measurement rather than the pre-#69 false-trip expectation.
